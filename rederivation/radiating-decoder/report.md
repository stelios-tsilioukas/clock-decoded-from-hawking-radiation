## Derivation (A5)

### Checks of the given inputs
- The physical-variable map is the Stirling saddle of the two-region disk with a clock chord of mass m.
- label_H = ln cos τ′.

### Classical reading
reading_cl = arg[sin((τ′ − κ₁ε/2 + iy)/2) sin((τ′ + κ₁ε/2 + iy)/2)]
- This is the 1d block with χ exchange. The cross-ratio is real, so only the prefactor carries phase.
- The reading is independent of Δ, h and Δ_χ, and equals −τ′ at the horizon.

### Decoded state with emission
The sector kept is the fully threaded one. The χ chord nests inside the emission chord, so nothing crosses.

**Regions:**
- **D, one per replica pair:** arc length 2π − 2τ_s.
- **σ, one per replica pair, between the χ chord and the emission chord:**
  - between two reference replicas: length 2τ_s − 2ε_e;
  - (previous reference, actual ket): length τ_s + ε/2 − 2ε_e − iy;
  - (actual bra, next reference): length τ_s + ε/2 − 2ε_e + iy.
  - Lorentzian parts: t always cancels, y does not.
- **E, shared by all replicas:** arc 2ε_e from each replica.

**Result, after continuing m → 0:**
- ρ_ab = ∫dμ(E) e^{−2sβε_e E²} K_a(E) K̄_b(E) / P(E)
- K_a(E) = ∫dμ(σ) e^{−sβ(τ_s + ε/2 − 2ε_e − iy)σ²} g_{Δe}(σ, E) S_a(σ)
- P(E) = ∫dμ(σ) e^{−sβ(2τ_s − 2ε_e)σ²} g_{Δe}(σ, E) F_χ(σ)

**Limits:**
- As Δ_e → 0, g_{Δe} → δ(σ − E)/μ(E), and ρ_ab reduces exactly (analytically) to Y⁰ = e^{−sβε s²} S_a S̄_b / F_χ.
- One-sided with emission: B's weight becomes e^{−sβ(ε − 2ε_e)B²} ∫dμ(E) e^{−2sβε_e E²} g_{Δe}(B, E). The effect is
  about 10⁻⁶.

### Numerics
- **Grid:** trapezoid rule in log space, h = 0.125.
  - h = 0.1 against 0.125: readings change by at most 2·10⁻⁸.
  - h = 0.2: changes of about 6·10⁻⁵.
- **Windows:** widening them by 8 changes nothing at 10⁻¹⁵.

## Doubts
1. **The Δ_e → 0 limit converges slowly.**
   - At L = −1 the decoded reading for Δ_e = 1, 0.5, 0.25, 0.1, 0.05 is −1.6843, −1.6838, −1.6823, −1.6800, −1.6798,
     against Y⁰ = −1.68758.
   - The cause is a hard-emission tail with weight ∼ 2Δ_e ln(1/(Δ_e√(sβε_e))).
   - So emission is a small perturbation of the decoder only if Δ_e ln(1/ε_e) ≪ 1.
2. **No dependence on t** for the stated ordering. Emission before the stop would need crossing chords (6j).
3. **Assumptions taken as given:**
   - the three-bilocal cubic vertex;
   - the large-μ brane;
   - only the fully threaded sector, with a naive m → 0 continuation. This affects |V| but not the phase.
4. **Classical reference:** the block at (τ′, κ₁y, κ₁ε), i.e. assuming the classical backreaction is purely a
   temperature shift.
